# Employee_Management_System
##Project Overview

The Employee Management System is a console-based Java application developed to manage employee records efficiently.
It allows users to add, view, update, delete, search employees, generate reports, and store employee data permanently using file handling, all through a menu-driven interface.

This project is created as part of the Week 4 Internship Task to demonstrate the use of Java Collections, File Handling, Exception Handling, and real-world data management concepts.

##Project Objectives

- To understand and use Java Collections (ArrayList)

- To implement CRUD operations (Create, Read, Update, Delete)

- To apply file handling for data persistence

- To practice exception handling using try-catch

- To build a structured, menu-driven console application

- To generate employee salary and department-based reports

##Technologies Used

- Java (JDK 8 or above)

- Spring Tool Suite (STS) / Eclipse

- Java Collections Framework

- Java File Handling

- Java Time API (LocalDate)

- GitHub

- GitHub Desktop

##Features

- Add new employee records

- View all employees in tabular format

- Search employees by ID, name, or department

- Update employee details

- Delete employee records

- Generate salary and department-wise reports

- Save employee data to file

- Load employee data from file

- Exception handling for file and input errors

- Menu-driven user interface

##How to Run the Project

- Install Java JDK (8 or above)

- Install Spring Tool Suite (STS) or Eclipse

- Clone or download this repository

- Open STS → File → Import → Existing Projects into Workspace

- Select the project folder and click Finish

- Make sure the data/employees.txt file exists

- Open EmployeeManagementSystem.java

- Right-click → Run As → Java Application

- Follow the menu instructions in the console

##Core Concepts Used

- Collections: ArrayList for storing employee objects

- File Handling: Reading and writing employee data to files

- Exception Handling: try-catch for safe file and input operations

- Encapsulation: Private fields with public getters and setters

- Modularity: Separate classes for data, file handling, reports, and logic
